# Marques

Ce dossier contient **une fiche par marque** accompagnée si besoin d'un dossier de ressources.

## Ajouter une marque

1. Copier `modeles/01-fiche-marque.md` vers `marques/nom-marque.md` (minuscules, tirets, sans accents).
2. Remplir la fiche avec le client ou avec Claude.
3. Placer les petits fichiers utiles (logo, photos du produit) dans `marques/nom-marque/`.

```text
marques/
├── README.md
├── nom-marque.md
└── nom-marque/
    ├── logo-fond-clair.png
    └── produit-face.jpg
```

## Rappels

- **Ce dépôt est public.** Ne rien y écrire de confidentiel (chiffres, projets non annoncés, contrats).
- Les photos du produit réel sont précieuses : elles servent de référence et évitent un produit déformé dans les plans générés.
- Garder la fiche à jour : une date de dernière mise à jour est indiquée en haut.
